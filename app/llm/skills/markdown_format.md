# SKILL: Структурированный вывод для MAX (plain-text)

V4 (2026-08-19): Pavel подтвердил — MAX UI **не рендерит markdown** для нашего бота
(`**жирный**` приходит как литералы). Этот skill — финальный вариант: plain-text
со структурой через эмодзи.

## Правила

- Используй **эмодзи-маркеры** для структуры: `▶`, `✅`, `⚠️`, `💡`, `📌`, `🔍`, `📝`, `🎯`, `🚀`.
- Буллиты — через `•` (одна точка) или `—` (тире), не через `-` (дефис).
- Разделы — пустая строка между ними.
- Заголовки — ЗАГЛАВНЫМИ БУКВАМИ или эмодзи-префикс (`▶ Заголовок`).
- **НИКОГДА** не пиши `**жирный**`, `*курсив*`, `# заголовок`, ```блок кода```, `> цитата` — MAX
  отрисует их как литералы (Pavel это видел на скрине 6).
- Ссылки: полный URL `https://example.com` — без Markdown-обёртки.

## Структура ответа

```
▶ ЗАГОЛОВОК

Текст абзаца. 2-3 строки максимум.

✅ Плюс: кратко
⚠️ Риск: кратко
💡 Идея: кратко

CTA: одно конкретное действие.
```

## Анти-паттерны (ЗАПРЕЩЕНЫ)

- "delve into", "leverage", "unlock", "unleash", "in today's fast-paced world"
- "game-changer", "revolutionize", "cutting-edge", "seamlessly", "robust solution"
- "elevate your", "take it to the next level"
- "I hope this helps", "Let me know if", длинные вступления без сути
- Markdown-разметка (`**`, `*`, `#`, `` ` ``, `>`, `---`, `[text](url)`)

## Пример: хорошо vs плохо

**Плохо (с markdown-разметкой — Pavel видит литералы):**
```
**Вариант 1**: для тех, кто думает.
ИИ-агенты — это уже **не будущее**.
- Программа, которая **сама** принимает решения
```

**Хорошо (plain-text + эмодзи):**
```
▶ ВАРИАНТ 1: для тех, кто думает

ИИ-агенты — это уже не будущее.

• Программа, которая сама принимает решения
• Не просто чат-бот — она действует: пишет, считает, бронирует
```

## Что ты получишь, если будешь следовать этим правилам

- MAX отрисует текст **корректно** (без мусорных `**`).
- Структура через эмодзи — пользователь быстро сканирует глазами.
- Никакого AI-шного послевкусия.

## 🐛 6. Edge cases

| # | Сценарий | Ожидаемое |
|---|---|---|
| 1 | Пустой ввод (только пробелы) | Бот молчит, не отвечает |
| 2 | Очень длинный текст (>4000) | Чанки по 3999 символов, MAX лимит соблюдён |
| 3 | Текст с эмодзи 🚀✨💡 | LLM обрабатывает, ответ тоже содержит эмодзи |
| 4 | Ссылка в тексте https://example.com | Markdown ссылка [example](https://example.com) |
| 5 | Markdown в тексте (жирный, курсив) | Sanitise() чистит — пустые пары `** **` удаляются |
| 6 | Картинка с >1500 символов prompt | Truncate до 1500 |
| 7 | Картинка с невалидным aspect_ratio (99:99) | Fallback на 1:1 |
| 8 | Картинка с 1008/1026 ошибкой MiniMax | User-friendly "💰 Недостаточно баланса" / "🚫 Контент заблокирован" |
| 9 | Два /start подряд | Бот не падает, перерисовывает меню |

## 🛠 Диагностика

**Если что-то не работает:**

1. Смотри `logs/bot_run.log` — там logger.info/warning/error от всех модулей
2. Специфические теги:
   - `maxbot.hermes.*` — Hermes client/session/dispatcher
   - `maxbot.image.*` — image_client (MiniMax)
   - `maxbot.menu.*` — кнопочный flow
   - `maxbot.executors.*` — _send_final / _send_long
   - `maxbot.max.client` — startup + регистрация slash-команд
3. Если бот не отвечает — `Get-NetTCPConnection -LocalPort 8080 -State Listen` в PowerShell
4. Если MAX ругается — ищи `400`/`BadRequest` в логе
